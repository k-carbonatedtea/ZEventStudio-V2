# Asset browser labels

`actor-names-zh.json` is the BOTW Chinese actor name table supplied with the local
ProjectRito reference (`MapStudio/Lib/Name/botwzh.json`).

`asset-profiles-zh.txt` contains the actor profile labels from the same reference
(`MapStudio/Languages/zhCN/AssetDirectories.txt`). Unknown actors and profiles keep
their original identifiers. These labels do not define actor behavior or runtime
placement parameters.
